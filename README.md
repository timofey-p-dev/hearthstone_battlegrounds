# Hearthstone Battlegrounds Clone

This project recreates the Battlegrounds system from Hearthstone. It is being developed as part of my portfolio.

## Features
 - Random damage instead of fixed 
 - Counter attack 
 - Random duels throughout the match 

## Installation
```bash
git clone https://github.com/timofey-p-dev/hearthstone_battlegrounds.git
cd hearthstone_battlegrounds
python main.py
```
